## Video Format (Optimized for Reels)

**Length:** 30-60 seconds (sweet spot)
**Structure:**
- 0-2s: Hook (text + visual)
- 2-10s: Setup/context
- 10-45s: Main content (2-3 key points)
- 45-55s: CTA (follow, save, comment)
- 55-60s: End screen/branding

**Visual Style:**
- Presenter centered, studio background
- Text overlays for key points
- Clean graphics (charts, arrows, numbers)
- Consistent color scheme (suggest: deep blue + gold)

**Voice/Tone:**
- Confident but approachable
- No jargon without explanation
- "Here's what this means for YOU"
- Direct, no fluff
